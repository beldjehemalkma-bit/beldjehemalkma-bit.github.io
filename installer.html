Installe ALKAMO sur ton téléphone

Deux appuis, aucun téléchargement, aucun avertissement. Le jeu s'ouvre ensuite en plein écran, comme une vraie application.

1Ouvre le menu du navigateur

Dans Chrome, appuie sur les trois points en haut à droite.

2Choisis « Installer l'application »

Dans le menu, appuie sur Installer l'application (ou « Ajouter à l'écran d'accueil »), puis sur Installer.

1Ouvre le menu Partager

Dans Safari, appuie sur le bouton Partager (un carré avec une flèche vers le haut), en bas de l'écran.

2« Sur l'écran d'accueil »

Fais défiler le menu, appuie sur Sur l'écran d'accueil, puis sur Ajouter.

1Cherche l'icône d'installation

Dans Chrome ou Edge, regarde à droite de la barre d'adresse : une petite icône « Installer » apparaît. Clique dessus, puis sur Installer.

🎮 Ouvrir le jeu

C'est tout ! L'icône ALKAMO apparaît sur ton écran d'accueil.
